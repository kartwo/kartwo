## 交付条件

最终仅保留 React + TypeScript + Vite + Ant Design 后台，删除 Vue 运行时、旧页面及迁移专用构建配置。保留现有 `/admin/#/...` 地址、Go API 和单二进制 embed 托管。菜单权限仅优化界面体验，服务端鉴权仍是授权依据。

当前处于分批迁移：`src/react` 已实现请求传输、会话/登录/初始化/邀请、向导流程、导航外壳和路由访问控制；收款、域名和 SMTP 三个实际配置页已接入向导；店铺品牌、博客开关及客服留存设置也已迁移，账号安全、翻译和备份设置也已迁移，配送和店铺政策设置也已迁移，用户与角色管理也已迁移，十二个设置页均按需加载；客服收件箱、日志、诊断、概览、关于、导入、导出、分类、固定内容管理、博客列表/编辑、商品列表/编辑及订单列表/详情十五个业务/系统页也已迁移。`index.html` 仍连接现有后台，**未切换正式入口、未发布 React 后台**。新组件由 `build:react` 独立编译验证到忽略目录 `.react-build`，不进入 Go embed；这项临时验证在正式入口切换时移除。

## 已迁移配置页的验收边界

收款按 Stripe/PayPal 分别保存；密钥只提交、不回填，保存后清空输入。环境变量配置只读，店主仍可测试已保存配置；员工不可进入收款与邮件，域名保留独立权限，演示不可保存或测试。域名保存保留重启及本地不签发证书提示；SMTP 保留密码空白字符和留空不变语义。向导复用相同页面；读取失败不展示可编辑空配置，401 清除会话，正在加载或提交时不能跳到下一步。

店铺品牌保留授权员工可编辑和演示只读，名称与 Logo 共用操作锁，上传失败保留旧图，上传或删除 Logo 不覆盖未保存的名称。博客及客服设置店主可写、员工只读；开关与留存数值严格解析，读取失败不展示默认可保存表单，保存失败保留输入供重试。完整留言留存 1–24 个月、IP 留存 7–90 天保持原有规则。

账号设置保留店主修改用户名/可选主密码及员工只改自身密码；确认成功后立即清空会话，错误密码保留当前会话。翻译密钥不回填、空值保留，页面加载和保存均不自动调用翻译。备份保留本地策略重启生效、WebDAV 保存后测试及冷启动所需环境配置提示；环境只读字段从写入中省略，密码空值省略且空白原样保留，配置保存失败不发起远端测试，测试失败仍清空已经保存的密码。全环境配置允许店主仅测试、无需提交只读值。

配送保留按洲分组、中文/英文/代码搜索、范围全选/清空、默认及特殊运费、规则新增/编辑/确认删除；金额使用十进制字符串和 BigInt 精确转分，拒绝舍入/指数/溢出。只读账号可搜索和查看规则，编辑动作依据 settings.shipping。特殊规则只能选已保存启用国家；删除正在编辑的规则后重置编辑器。政策资料保留七洲时效，最大天数须不小于最小天数；资料编辑依据 settings.policy，生成页面额外需要 content.manage。生成前保存当前资料，覆盖正文前确认；取消不写入，保存失败不生成，生成失败明确已保存资料。现有草稿/发布保留语义继续由后端生成器负责。

用户与角色页面仅店主可访问；预设角色名称固定但权限可编辑，自定义角色可创建、改名、改权和删除，店主超管单独展示且无员工操作入口。角色依赖按现有服务端规则校验，用户/角色/会话/退款等店主专属权限不出现在可分配清单。邀请、停用/恢复、角色调整、密码重置和退出设备沿用原接口；重置、退出设备和删角色均先确认，仍有员工的角色须先调整。邀请链接严格限定本站固定入口与令牌格式，仅保留当前页面内存，支持复制/隐藏，跳页或会话过期清除。写入成功而列表刷新失败保留刚生成的邀请及成功结果，明确提示刷新核对，不误报写入失败或自动重发。

客服收件箱保留状态筛选、私密详情、处理人/结案人快照、可信国家与 IP、匿名化和结案/重开。contact.view 只读、contact.manage 可处理；演示即使错误返回真实内容也不展示。选中变化取消旧读取并核对对象 ID，旧详情不能覆盖当前对象；状态写入期间锁定切换和重复提交，401 清除内容。审计保留最近 100 条、操作时用户名、未知动作文本回退和演示标识脱敏，读取失败显示重试。诊断保留数据库、媒体、磁盘和备份/升级快照；未知状态或错误不冒充正常，磁盘探测失败仍展示其他诊断。

概览保留订单数量与已确认净销售额、待发货、未删除商品总数、可售库存告警和开店配置引导；正确说明商品计数含草稿，已配置不等于真实交易和 HTTPS 已验收，操作入口逐项按权限显示。关于页保留 MIT 提示。全量导出仅店主获得原生下载链接，新标签页由服务端流式提供 ZIP，前端不整包缓冲，演示无链接；下载及错误需实际浏览器确认。CSV 保留通用/Shopify 来源与预览/行错误/确认流程，5MB 上限；文件或来源变化清除旧预览和错误，忙碌期间锁定选择与重复确认，返回结果绑定来源和任务 ID。已成功任务不再提供确认，断线可通过原任务只读核对后再决定是否重试，不自动重建任务。

分类保留名称/slug/非负整数排序、商品计数及关联保护，products.view 可看、categories.manage 可改；新建 slug 跟随完整英文名称直到手改。内容页保留安全 Markdown 原文、SEO、草稿/发布、固定链接和确认删除；演示可选页查看，写入仍需 content.manage。详情切换取消旧读取并核对对象；新建确认成功即固定公开 ID，即使列表刷新失败也不重新 POST，保留已存原文和成功结果；删除当前页后重置编辑器。

博客保留独立列表、新建和编辑地址，以及摘要、SEO、固定 slug、草稿/发布、确认删除、封面与正文图片、旧 Markdown 预览转换。复用唯一标题链接生成逻辑；用户手改后停止自动覆盖，重名候选不替代服务端冲突校验。保存直接读取编辑器的最新 DOM 正文；封面/正文上传和保存共用锁，上传完成后恢复编辑态再插图，避免图片遗漏并保留浏览器撤销。blog.view 员工只读，blog.manage 才可写；演示直接不读取真实文章。详情取消旧读取并校验对象，加载失败不呈现空白可保存页，401 清除编辑器。

富文本不引入新依赖，保留原生工具栏命令、选区、标题/引用/列表/字体/颜色/字号/行高/对齐/缩进/表情/表格/链接/图片/视频和撤销重做。所有加载与保存内容经浏览器白名单过滤；仅本地博客 WebP 图片、HTTPS/站内链接和规范 YouTube/Vimeo 播放器，粘贴/拖入仅文字；Go 服务端仍作最终过滤。排版下拉操作后清空，允许对不同选区重复应用同一个选项。隔离 IAB 预览已检查加粗、标题、站内链接、撤销/重做、颜色、表格和行高，控制台无错误；未连接真实数据，不能替代正式路由的图片上传、视频加载、旧文章迁移和多身份验收。

商品保留独立列表/新建/编辑、精选与删除、中文辅助字段和手动 DeepL 翻译、英文链接、分类、草稿/上架/归档、轴和组合、逐行价格库存、图片与 alt。分类目录读取失败不显示可保存的空分类，媒体读取失败不当空图集；详情切换取消旧读取并校验对象。新建后进入已确认公开 ID 的编辑地址，后续读取失败可重试，不重复 POST。矩阵改轴后必须重新生成，取消重建保留原价格；价格空白拒绝而显式 0 可用，十进制精确转整数分，库存拒绝空白/负数/小数/溢出。巨大组合以既有后端 1MB 请求上限的字节下界提前拒绝，不新增业务配额。

商品基本编辑、上架、价格、库存、媒体分别按服务端已有权限；仅改价或仅库存的员工可独立保存对应字段，不要求同时持有两项权限。只提交有变化的字段，改价格不回写未改的旧库存。两个端点不承诺原子提交：价格成功后库存未确认时保留价格基线和输入，明确提示核对，下一次不重复价格请求；401 仍清除整个会话。字段/翻译/变体/媒体共用写锁。图片白名单只接收本地内容哈希路径，上传成功后读列表失败仍保留返回的资产，图片更新不覆盖未保存的基本信息或其他图片 alt。演示的示例商品只读，自有临时商品可维护，状态固定草稿、创建额度沿用会话值、最多一张图片且限会话大小；只有店主可手动触发翻译，不自动请求 DeepL。

订单列表保留全部订单和详情地址；店主通过原生新标签页下载 CSV，保留状态和 UTC 日期范围（包含结束当天），不在浏览器整包 Blob 缓冲。列表仍读取当前完整列表并在客户端分页，服务端搜索/分页工作台属于后续 B1，不追认完成。客户权限在解析前再次丢弃邮箱、姓名/电话/地址/国家、运单和付款/退款参考号；员工无客户资料时只能看业务状态，演示始终脱敏只读。详情核对对象 ID，取消切换前的读取，401 清除整页。

订单详情独立显示金额/运费快照、资金与履约状态、收款/平台核对屏障、商品、历史退款、持久退款请求，以及退款后仍保留的运单。金额用整数分精确展示，校验安全整数、币种一致性及收款合计；未知状态不冒充正常。员工发货需 orders.fulfill 和 orders.customer_data，且资金已确认、未发货、无未决退款/核对屏障；付款引用、金额退款、平台清单核对及撤销顾客访问仅店主。撤销需确认且不改变付款或运单。

退款逐付款选择、二次确认币种和金额，既有正数精确转分逻辑与 Node 回归测试继续共用。结果未知保留原付款、金额、已退基线和 UUID 幂等键，冻结新退款与发货；刷新不清除原请求，继续时 payload 完全相同且不并发重提。键只留当前订单页内存，不进入浏览器持久存储；离开或重新登录后应按服务端持久退款记录核对，不凭新键猜测原结果。新退款、继续处理和平台清单核对共用锁，平台核对不新增退款。写入确认后读详情失败，保留已知请求 ID/状态并暂停新退款与发货，允许继续原请求核对；只有新的已校验详情对象才能解除刷新限制。本地表单校验失败不触发该限制。客户端可见性和屏障仍不替代服务端鉴权、余额、租约与平台核对。

当前 30/30 个原视图已实现，十二个设置页及十五个业务/系统页使用独立动态导入；另有三个向导视图组合复用设置页。唯一入口切换、移除 Vue、生产包体审查及正式浏览器/权限/业务验收仍待完成。接口桩测试不代表真实支付平台或 SMTP 验收。

## 验证方式

- `npm test`：原有 Node 测试 + React DOM、路由、会话和传输测试。
- `npm run typecheck`：严格 TypeScript 检查。
- `npm run build`：测试、新组件编译检查、当前正式入口构建。
- `npm audit --registry=https://registry.npmjs.org --audit-level=high`：包含开发依赖的安全门禁。

React DOM 测试文件以单 worker 顺序执行，避免每个 jsdom/Ant Design 实例同时加载造成资源争抢；用例内部的请求并发与竞态断言仍保留，未放宽超时或删减场景。

React DOM 测试使用隔离 API 桩，不修改验收数据，也不等于真实浏览器、SMTP 或支付平台验收。完整迁移后复用常驻验收库，不要求清空或重建商品与配置。

## 博客正式入口切换后的人工验收

1. 复用已有常驻验收库进入后台，不清空商品或配置；迁移期间无需重填数据。正式入口尚未切换时，现有页面仍为旧后台。
2. 在“博客文章”新建草稿，输入英文标题确认链接跟随标题；手改链接后继续改标题，确认不覆盖。加粗、设置标题和颜色、插入表格，分别上传封面和正文图片。
3. 保存后从列表重新打开，确认图文、封面、链接和草稿状态保留；发布后打开店面文章核对图片和排版。保存后的链接应固定。
4. 打开一篇旧 Markdown 文章，检查转换提示和原图文；保存后重新打开确认内容。视频使用 YouTube/Vimeo 链接，错误链接应提示且不插入。
5. 用只有 blog.view 的员工查看，确认可以阅读、不能上传保存删除；公开演示不显示真实草稿。完整权限回归在统一切换时执行。

## 商品正式入口切换后的人工验收

1. 复用常驻验收库进入“商品”，无需清空已有商品和图片。当前正式入口仍是原后台，完整迁移后再切换验收。
2. 新建草稿，填写英文标题，确认自动生成链接；设置一个轴和几个取值，生成组合。价格留空应阻止保存，填 0 或两位小数可保存，库存须为整数。
3. 填好价格后更改轴，确认提示重新生成；取消重新生成时原输入应保留。保存后进入编辑页，链接固定，上传图片并填写英文 alt。
4. 修改当前行价格与库存并保存，重新打开核对；只改价格时，不应重设其他库存。用只有改价或库存权限的测试员工，确认只能维护对应字段，不能因此编辑基本信息或上传图片。
5. 草稿改为上架并保存，回店面核对；精选只对上架商品开放。删除商品和图片前均应确认，取消不删除。
6. 演示中已有示例商品只读，自有商品只能是草稿，达到临时商品/图片额度后禁用继续创建或上传。翻译由店主手动点击；未配置服务只提示，不自动发送文字。

## 订单正式入口切换后的人工验收

1. 复用常驻验收库，只使用支付沙箱订单验收退款与发货，不重建商品或配置。迁移中的正式入口尚未切换。
2. 在列表打开订单，核对金额、运费、付款和发货状态；店主导出 CSV，分别选择状态和起止日期，确认包含结束当天，错误日期范围不能导出。
3. 用授权员工验证收货信息与发货；缺少客户资料权限时邮箱、地址和支付参考号应隐藏，也不能发货。演示只读脱敏；员工没有退款、平台核对或撤销访问入口。
4. 在一笔有可退余额的沙箱订单上选择付款，填写小额退款，核对确认框中的交易号、币种和金额。取消不提交，确认后在持久退款请求中查看状态。退款后原发货记录应保留。
5. 待核对请求优先“继续原退款请求”或填写平台退款编号核对，不新建重复退款。详情刷新失败时应暂停新退款和发货，刷新确认最新记录后才恢复；未知原请求仍需继续核对。
6. 在沙箱订单确认“撤销顾客访问”，原设备查看凭证应失效，顾客仍可用订单邮箱重新验证；订单与付款状态不变。真实 SMTP/支付回调、跨设备与生产部署另按 A 阶段验收，当前接口桩测试不能替代。
